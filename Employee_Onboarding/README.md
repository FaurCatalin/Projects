# Employee Onboarding System

Full-stack web application for managing the employee onboarding process.

---

## Project Overview

This application simulates a real onboarding workflow involving multiple departments:

- HR creates employee profiles
- Manager approves employees
- Finance approves (only for Premium hardware)
- IT provisions equipment
- Completion or rejection with rework

---

## Features

- Create new employees
- Manager approval stage
- Finance approval (conditional)
- IT provisioning
- Completion workflow
- Reject and resubmit functionality
- Dashboard with live data
